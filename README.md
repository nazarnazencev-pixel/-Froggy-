# ru Russian Version
# 🐸 Froggy — Custom File Manager

> Современный кастомный файловый менеджер с минималистичным интерфейсом и быстрой навигацией.

Froggy — это экспериментальный файловый менеджер, созданный как альтернатива стандартному проводнику Windows.  
Проект сочетает в себе удобный интерфейс, современный дизайн и высокую скорость работы.

---

## ✨ Возможности

- 📂 Управление файлами и папками
- ⚡ Быстрая навигация
- 🎨 Кастомный современный интерфейс
- 🖥 Удобная работа с файловой системой
- 🔍 Минималистичный UI
- 🚀 Высокая производительность

# 🇺🇸 English Version

# 🐸 Froggy — Custom File Manager

> A modern custom file manager with a minimalistic interface and fast navigation.

Froggy is an experimental file manager designed as an alternative to the default Windows Explorer.  
The project combines a clean UI, modern design, and smooth file system interaction.

---

## ✨ Features

- 📂 File and folder management
- ⚡ Fast navigation
- 🎨 Custom modern interface
- 🖥 Comfortable file system interaction
- 🔍 Minimalistic UI
- 🚀 High performance
